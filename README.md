# Tiny Dungeons

Tiny Dungeons is a procedural dungeon crawler developed with Lua and LÖVE2D.

The project is being built incrementally as a practical study of game development, Entity Component System architecture, procedural generation, animation and physics.

## Planned features

- Procedurally generated dungeons
- Animated player and enemies
- Physics-based collision detection
- Keyboard and gamepad support
- Enemy pathfinding
- Dynamic lighting and shadows
- Chests, items and combat

## Technology

- Lua
- LÖVE2D
- Concord
- Roomy
- Baton
- Anim8
- Astray
- Breezefield
- Ninja Adventure Asset Pack

Additional libraries will be introduced only when the corresponding functionality is implemented.
